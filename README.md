## Pokemons (RTK Query + react bootstrap)

## How to run: 
npm install && npm run dev

## Features

- Pokemon list with pagination (limit / offset)
- Pokemon details displayed in a modal
- Data fetching with RTK Query
- Prefetch Pokemon details on hover
- Skip details request when no Pokémon is selected
- Loading, error and empty states
