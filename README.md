✔️ Завантаження та відображення альбомів

Дані отримуються з https://jsonplaceholder.typicode.com/albums.

Альбоми показані у вигляді бокової панелі (Sidebar).

Додано інпут пошуку, який фільтрує альбоми за title.

Під час завантаження показується Loader, а у випадку помилки — Message.

✔️ Вибір альбому та показ фотографій

При кліку на альбом завантажуються фото за API:
https://picsum.photos/seed/1000/800

Фотографії відображаються у вигляді ґріда карток з мініатюрами.

Під час завантаження та помилки — відповідні RSuite-компоненти (Loader, Message).

✔️ Перегляд фото в модалці

Клік по картці відкриває Modal з великим зображенням.

Додано:

кнопки Next / Prev

управління клавіатурою (← → Esc)


✔️ Кешування фото

Якщо альбом уже відкривався — повторне завантаження не виконується.

✔️ Структура стану

Увесь стан зберігається у верхньому компоненті App:

список альбомів

вибраний альбом

завантаження та помилки

Компоненти отримують дані через пропси.
